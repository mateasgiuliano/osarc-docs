## Docs

Docs is your writing space. Folders hold pages. A page can be a document, a database, or a canvas.

- **Writer**: a rich text page. Headings, lists, images, embeds.
- **Database**: a table with typed columns and views.
- **Canvas**: a freeform whiteboard for diagrams and sketches.

Pin pages you use every day. Put a page on the desktop to keep it one click away. Quick notes go to your personal Quick Notes folder.

### Sharing

Sharing is by folder. Share a folder with a team member and they see every page in it. Personal folders are yours alone.

### ARC and Docs

ARC can read your docs when you ask it to, and can write a page for you: "write up today's call notes into a page in the Sales folder".

## Sheets

ArcSheets is a spreadsheet. Formulas, multiple sheets, import from a file. Use it for anything you would reach for a spreadsheet for, and keep it next to the data it is about.
